# An Explainable Dual-Channel Stacking Framework with Attention-Based Deep Learning for Heart Disease Prediction Using Clinical Features

## Overview

This research presents an Explainable Dual-Channel Stacking Framework with Attention-Based Deep Learning for Heart Disease Prediction using clinical features.

The framework aims to combine the predictive capabilities of multiple learning channels through a stacking-based approach while incorporating attention mechanisms and explainability techniques.

## Research Objectives

- Develop a dual-channel framework for heart disease prediction.
- Utilize attention-based deep learning techniques.
- Apply stacking-based prediction fusion.
- Improve model interpretability through explainable AI techniques.
- Evaluate the framework using standard classification metrics.

## Dataset Description

This research uses the Combined UCI Heart Disease Dataset
containing 920 patient records.

## Dataset Source & Attribution

The dataset used in this research was obtained from Kaggle.

### Data Splitting

- Total Samples: 920
- Training Samples: 736 (80%)
- Testing Samples: 184 (20%)
- Splitting Strategy: Stratified Train-Test Split
- Random State: 42

### Target Variable

The original target variable is converted into binary classification:

- 0: No Heart Disease
- 1: Heart Disease
